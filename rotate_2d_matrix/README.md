# Rotate 2D Matrix

This project contains a Python function that rotates an $n \times n$ 2D matrix 90 degrees clockwise in-place.

## Requirements
* Allowed editors: `vi`, `vim`, `emacs`[cite: 1]
* Interpreted/compiled on Ubuntu 14.04 LTS using `python3` (version 3.4.3)[cite: 1]
* All files should end with a new line[cite: 1]
* The first line of all files should be exactly `#!/usr/bin/python3`[cite: 1]
* Code should use the `PEP 8` style (version 1.7.x)[cite: 1]
* No modules are allowed to be imported[cite: 1]
* All modules and functions must be documented[cite: 1]
* All files must be executable[cite: 1]

## Function Prototype
* `def rotate_2d_matrix(matrix):`[cite: 1]
  * Rotates the given $n \times n$ 2D matrix 90 degrees clockwise.
  * Modifies the matrix **in-place** (does not return anything)[cite: 1].

## Files
* `0-rotate_2d_matrix.py`: Python function to rotate a 2D matrix.
* `main_0.py`: Test file to verify the functionality of the rotation function.
